# Decision records

Short records of choices that are easy to "fix" back by mistake. Agents must
read the relevant ADR before changing code it covers, and add a new one
(next number, never edit an accepted one's decision) when reversing it.

Template: `NNNN-title.md` with **Status**, **Context**, **Decision**, **Consequences**.
